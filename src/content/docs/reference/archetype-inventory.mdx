Every exam in this course is built from these ten archetypes, and no others. Both exams are multiple choice: each item is one archetype posed as a question with one correct option, and the wrong options are the mistakes students really make. You practice all ten archetypes in activities, assignments, and recitations, so nothing on the exam is a surprise. On exam day you meet fresh variations: new values and new contexts, but the same ten skeletons.

You never write code on an exam. Where an archetype is about producing code, the exam shows candidate versions and asks which one is correct; you practice the producing itself on the assignments and in the recitations.

## The ten archetypes

1. **Evaluate.** Which value, and which type, does this expression produce? Covers precedence, integer versus float division, boolean logic, and string operations.
2. **Trace.** Which variable-value table correctly traces this loop or function call, or what is the value of a variable after a marked line?
3. **Predict output.** Read a short program. Which of these is exactly what it prints?
4. **Find the bug.** Read a program with one logic error. Which line is wrong, or which fix makes the program correct?
5. **Choose the implementation.** Given a short specification, which of these candidate functions meets it? This is the multiple-choice face of writing a function; the writing itself happens on assignments and in recitations.
6. **Pick the memory diagram.** Which diagram of names, values, and references matches the program's state after a marked line, or which call stack matches a marked moment?
7. **Explain.** Which one-sentence description states what this function does, at the level of purpose rather than line by line?
8. **Choose tests.** Given a specification, which test case can tell a correct implementation from a broken one, and which case sits exactly on the boundary? The final adds the floating-point traps.
9. **Complete the code.** Which line correctly fills the labeled blank in a program that is mostly written for you?
10. **Concept question.** A short concept question, such as compile-time versus run-time errors, why `0.1 + 0.2` is not equal to `0.3`, or when a value is copied versus when a name is shared.
