The course wears two story lines, one for take-home practice and one for the supervised tiers, and the story is always skippable and never changes the technical task.

## Mission Ares (recitations and exams)

In recitations and exams the class is the flight software crew of a crewed Mars habitat. The recurring character is HAB, the habitat's onboard AI assistant. HAB is helpful, tireless, and confidently wrong at convenient moments, and that is how find-the-bug and judge-this-code problems arrive in the story: HAB drafts a piece of code and hands it to you to sign off or reject. The flight rule is simple: no HAB code runs unverified. You always check HAB's work before it counts.

## Rubber Duck Robotics (assignments)

Assignments are set at Rubber Duck Robotics, a mediocre but lovable novelty-gadget company that makes things like self-stirring mugs and motivational bathtub ducks. You are the new firmware intern. Every assignment arrives as a ticket from Gary, the senior engineer, who is enthusiastic, overcommitted, and reliably wrong about one thing per week. Gary usually sends a helper function that looks convenient but is subtly wrong. Copying it without checking costs you a visible test, so read what Gary gives you before you trust it.

## The problem families and their two faces

Each problem family is one concept skeleton worn as a different costume in each tier. The same skeleton shows up as a Rubber Duck Robotics ticket in assignments and as a Mission Ares mission task in recitations and exams. Every problem can be solved while ignoring the plot.

| Family | Rubber Duck face (assignments) | Mission Ares face (recitations, exams) | Core topics |
|---|---|---|---|
| **Launch Window**: arithmetic with units and time | Duck-race countdown timers, novelty-mug fill volumes | Sols vs Earth days, fuel mass fractions, delta-v budgets | Expressions, types, variables, functions |
| **Airlock**: decision tables and interlocks | Hot-tub controller: temperature, occupancy, and timer cutoff rules | Never both doors open, pressure thresholds, suit checks | Booleans, conditionals, decision tables |
| **Rover**: loops over state and grids | Warehouse duckbot fetching parts, ASCII duck-parade rendering | Drive commands, battery budget, terrain rendering | Loops, loop patterns, nested loops, functions |
| **Comms**: encode, decode, clean a sequence | Garbled customer order codes, novelty-pager messages | Ciphers, checksums, packet buffers | Strings, lists/vectors, memory model, sharing |
| **Telemetry**: validate and summarize a noisy stream | The smart bathtub's water-level sensor returns nonsense | Dust-storm sensor streams, tolerance alarms | Errors, input validation, floating point, RNG noise |
| **Manifest**: key-value lookup and counting | Duck SKU inventory after a warehouse mix-up | Cargo inventory, resupply planning (the Rust pun is intended) | Dictionaries/hashmaps, choosing structures |
