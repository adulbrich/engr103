These are one-page concept maps for languages some majors use downstream. Each maps the course subset construct by construct, in ladder order, and ends with a short `### What will surprise you` list. See the [language ladder](/reference/language-ladder) for the subset itself. The middle column shows the Python form of each construct; the Rust form maps the same way. Cells hold short fragments, not full programs. Two languages for now: Fortran, for the nuclear and HPC-bound, and R, for the statistics-bound in bio, environmental, ecological, and industrial engineering.

### What will surprise you

- **It is 1-indexed.** The first element is `xs(1)`, not `xs(0)`, and the last is `xs(size(xs))`. Indexing uses parentheses, the same syntax as a function call, so `xs(1)` and `add(1)` look alike.
- **Everything is declared, with a fixed type.** Every variable needs a type declaration before use, such as `integer :: x`, and putting `implicit none` at the top turns any undeclared name into an error. A variable's type and an array's size are fixed at declaration, so you cannot reassign a variable to a different type the way the dynamic course subset lets you.
- **`do` is the only loop word.** Both the counted loop (`do i = 1, n`) and the conditional loop (`do while (c)`) start with `do` and close with `end do`. The range in `do i = 1, n` is inclusive and 1-based, so it runs `n` times.
- **It is array-first.** Whole-array expressions are idiomatic: `ys = xs * 2` doubles every element with no loop, and intrinsics like `sum(xs)` and `size(xs)` act on the entire array at once. Reaching for a loop where a whole-array expression exists is the habit the course subset does not have.

## R

| Concept | Course subset (Python or Rust) | R |
|---|---|---|
| Print a value | `print(x)` | `print(x)` |
| Print with a placeholder | `print(f"x = {x}")` | `cat("x =", x, "\n")` |
| Integer literal | `x = 5` | `x <- 5L` |
| Float literal | `y = 2.5` | `y <- 2.5` |
| Boolean literal | `b = True` | `b <- TRUE` |
| String literal | `s = "hi"` | `s <- "hi"` |
| Arithmetic and precedence | `a + b * c` | `a + b * c` |
| True division | `7 / 2` is `3.5` | `7 / 2` is `3.5` |
| Floor division | `7 // 2` is `3` | `7 %/% 2` is `3` |
| Variable and assignment | `x = 5` | `x <- 5` |
| Reassign | `x = 6` | `x <- 6` |
| Constant (naming convention) | `MAX = 10` | `MAX <- 10` |
| Function returning a value | `def add(a, b): return a + b` | `add <- function(a, b) a + b` |
| Function with no return value | `def greet(n): print(n)` | `greet <- function(n) cat(n, "\n")` |
| Call a function | `s = add(2, 3)` | `s <- add(2, 3)` |
| Comparisons | `a == b`, `a < b`, `a != b` | `a == b`, `a < b`, `a != b` |
| Boolean operators | `a and b`, `a or b`, `not a` | `a && b`, `a \|\| b`, `!a` |
| `if` / `elif` / `else` | `if c:` / `elif d:` / `else:` | `if (c) {`<br />`} else if (d) {`<br />`} else {`<br />`}` |
| `while` loop | `while c:` | `while (c) {`<br />`  # body`<br />`}` |
| Counted `for` loop | `for i in range(1, n + 1):` | `for (i in 1:n) {`<br />`  # body`<br />`}` |
| Array literal | `xs = [1, 2, 3]` | `xs <- c(1, 2, 3)` |
| Index an element | `xs[0]` | `xs[1]` |
| Length | `len(xs)` | `length(xs)` |
| Iterate over elements | `for x in xs:` | `for (x in xs) {`<br />`  # use x`<br />`}` |
| Append to the end | `xs.append(4)` | `xs <- c(xs, 4)` |
| Whole-array operation | `for i in range(len(xs)):`<br />`  ys[i] = xs[i] * 2` | `ys <- xs * 2` |
| String character | `s[0]` | `substr(s, 1, 1)` |
| Slice | `s[1:3]` | `substr(s, 2, 3)` |
| Search within a string | `"lo" in s` | `grepl("lo", s)` |
| Concatenate strings | `s = s + "!"` | `paste0(s, "!")` |
| String length | `len(s)` | `nchar(s)` |

### What will surprise you

- **It is 1-indexed.** The first element is `xs[1]`, not `xs[0]`, and there is no `xs[0]`. A negative index like `xs[-1]` does not mean "the last element"; it means "everything except the first."
- **Operations are vectorized.** `xs * 2` doubles every element and `xs + ys` adds two vectors element by element, no loop needed. Most built-in functions accept a whole vector at once, so an explicit `for` loop over elements is usually a sign you are working against the language.
- **`<-` is the assignment operator.** `x <- 5` is the idiom; read it as "gets." A plain `=` also assigns, but by convention it is reserved for named arguments inside a function call, so the two are not interchangeable in practice.
- **Everything is a vector.** A plain number is just a length-one vector, so `x <- 5` and `xs <- c(1, 2, 3)` are the same kind of thing. There is no separate scalar type, which is why `length(5)` is `1` and why vectorized operations apply uniformly whether a value holds one element or many.
