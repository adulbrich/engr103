The lecture notes are the material you read **before** each class. Each note teaches one concept from the ground up: what it is, why it exists, how it works underneath, and how it looks running in real code. Class time then assumes you have done the reading, so the session is spent applying the concept rather than first hearing it. A note is written to stand entirely on its own, so a lecture you missed is never lost: the note is the lecture.

## Two Languages, One Set of Ideas

Every concept in this course is taught twice, once in **Python** and once in **Rust**, side by side. The idea is the same in both; the two languages simply show it from two angles. Python runs your code immediately through an interpreter, which makes it quick to try an idea and see what happens. Rust compiles your code first, and its compiler checks far more before the program ever runs, which turns many mistakes into clear messages you get up front. Seeing one idea in both languages is what separates the concept from the syntax: you learn what a variable, a loop, or a function *is*, not just how one language spells it.

Because you are learning two languages at once, the course keeps the set of constructs small and grows it one week at a time. The [Language Ladder](/reference/language-ladder/) lists exactly what is available each week, so nothing in a note or an assignment ever depends on something you have not been taught yet.

## How the Notes Are Organized

There are eighteen lectures across ten weeks, two each week. The first half, through the midterm, builds the foundations: how a program runs, how values are stored, expressions, variables, functions, scope, conditionals, errors, and testing, all without iteration. The second half adds the tools that make larger programs possible: loops, strings, collections, and the memory model that explains how data is shared and changed. The full week-by-week map, with which assignment and recitation each lecture feeds, is on the [Schedule](/overview/schedule/).
