This is the weekly map of the course: eighteen lectures across ten weeks, two
each week (Monday and Wednesday), with the midterm in week 6. Each week lists its
lectures, the assignment due that week, and the recitation. Lecture names link to
the notes, which are read before class; the right column names the topic or
problem family.

The first half, through the midterm, teaches the foundations, functions, scope,
conditionals, errors, and testing without iteration; loops and data come after
the midterm. **All learning outcomes are met by the end of week 9;** the two
week-10 lectures are advanced extras, not required for the outcomes. The weekly
rhythm is Lecture A, then the recitation (with that week's assignment due just
before it), then Lecture B.

## Week 1

| | |
|---|---|
| **Lecture 1: [How Programs Run](/lectures/how-programs-run/)** | Computation, interpreters and compilers, errors as messages, the systematic debugging method, modeling versus analysis, the two-language philosophy |
| **Assignment 0** | Setup, toolchains, hello in both languages |
| **Recitation 1 (ungraded)** | Onboarding: environment, terminal, editor, the `check` harness |
| **Lecture 2: [Data Representation and Memory](/lectures/data-representation/)** | Values and types, static versus dynamic typing, binary, bits and bytes, memory as addressable boxes, integer sizes; taught with the interactive binary and memory-box tools |

| **Recitation 2** | Expressions and types |
| **Lecture 4: [Variables and State](/lectures/variables-and-state/)** | Names versus values, assignment and rebinding, `let`/`let mut`, initialization, constants, tracing with the memory stepper |

| **Recitation 4** | Functions and scope synthesis |

| **Recitation 5** | Conditionals and decision tables |
