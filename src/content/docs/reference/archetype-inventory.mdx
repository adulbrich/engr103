Every exam in this course is built from these ten question types, and no others. Students practice all ten in activities and assignments, so nothing on the exam is a surprise. On exam day they meet fresh variations: new values and new contexts, but the same ten skeletons.

## The ten archetypes

1. **Evaluate.** Compute the value and the type of an expression, covering precedence, integer versus float division, boolean logic, and string operations.
2. **Trace.** Fill in a variable-value table for a loop or a function call, line by line.
3. **Predict output.** Read a short program and write exactly what it prints.
4. **Find the bug.** Read a program with one or two logic errors, then identify each error and fix it.
5. **Write a function.** Write a function on paper from a short specification, about 8 to 15 lines.
6. **Draw memory.** Draw a diagram of names, values, and references before and after a marked line, or draw the call stack at a marked moment.
7. **Explain.** State in one or two sentences what a function does, at the level of purpose.
8. **Choose tests.** Given a specification, propose test cases and identify the boundary cases and error cases, plus the floating-point traps on the final.
9. **Complete the code.** Fill in the labeled blanks in a program that is mostly written for you.
10. **Concept short answer.** Answer a short concept question, such as compile-time versus run-time errors, why `0.1 + 0.2` is not equal to `0.3`, or when a value is copied versus when a name is shared.
